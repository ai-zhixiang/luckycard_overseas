Authentication

Every API call must include your key in the X-API-Key request header. Keys start with lc-. Keep them secret — anyone with the key can spend your points. 

X-API-Key: lc-0123456789abcdef0123456789abcdef
Endpoint: https://hicard.world
Free daily quota: 3 AI operations per IP. Calls made with an API key are billed to your wallet (no free quota used).

GET/api/apikey/verify

Check whether a key is valid. Does not count as a use and does not charge points.

curl https://hicard.world/api/apikey/verify \
  -H "X-API-Key: lc-your-key-here"
{
  "valid": true,
  "uid": "u_8f3a...",
  "label": "my-script",
  "balance": 240
}
import requests

r = requests.get(
    "https://hicard.world/api/apikey/verify",
    headers={"X-API-Key": "lc-your-key-here"},
    timeout=15,
)
print(r.status_code, r.json())   # 200 + {"valid": true, ...}  (401 = bad key)

GET/api/v1/balance

Query the balance of the account that owns this key. Free — no points charged.

curl https://hicard.world/api/v1/balance \
  -H "X-API-Key: lc-your-key-here"
{
  "uid": "u_8f3a...",
  "label": "my-script",
  "balance": 240,
  "prices": { "poem": 10, "vision": 10, "art": 15, "stylize": 15 }
}
import requests

r = requests.get(
    "https://hicard.world/api/v1/balance",
    headers={"X-API-Key": "lc-your-key-here"},
    timeout=15,
)
d = r.json()
print(f"balance: {d['balance']} points")
print(f"prices: {d['prices']}")

POST/api/v1/poem − 10 points

Generate a personalized poem. The recipient name is always woven into the text. On failure the points are refunded automatically.

FieldTypeDescription
recipientstringWho the poem is for (e.g. Mom)
occasionstringOccasion (e.g. birthday, New Year)
messagestringYour own note, woven into the poem
curl -X POST https://hicard.world/api/v1/poem \
  -H "X-API-Key: lc-your-key-here" \
  -H "Content-Type: application/json" \
  -d '{"recipient":"Mom","occasion":"birthday","message":"thank you for everything"}'
{
  "poem": "For Mom, on this birthday bright...",
  "charged": 10,
  "balance": 230
}

Python (requests):

import requests

API_KEY = "lc-your-key-here"
BASE = "https://hicard.world"

r = requests.post(
    f"{BASE}/api/v1/poem",
    headers={"X-API-Key": API_KEY},
    json={
        "recipient": "Mom",
        "occasion": "birthday",
        "message": "thank you for everything",
    },
    timeout=60,
)

if r.status_code == 401:
    print("Invalid API key — check the X-API-Key header")
elif r.status_code == 402:
    d = r.json()
    print(f"Not enough points: need {d['cost']}, have {d['balance']}")
else:
    r.raise_for_status()
    d = r.json()
    print(d["poem"])
    print(f"charged {d['charged']}, balance {d['balance']}")

Errors

CodeMeaning
401Missing or invalid API key
402Insufficient Lucky Points — recharge at My Wallet
429Rate limited — slow down
502Upstream AI service failed — points refunded
A 402 response body includes cost and balance so your program can handle low balance gracefully.

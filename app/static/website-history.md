# hicard.world 网站编年史

> 口述整理中……空壳期细节待 boonxiong2 补充
> 起源:爸爸(上海)给儿子(boonxiong2,香港)手机,叫他帮忙做网站 —— 儿子动手,第一个加的东西就是 BIOS 动画
> 背景:爸爸先做了**国内版**——纯网页,点进去直达主页面,无开机动画,UI 是 AI 搭的配色(类似 Adobe 风格);儿子的 hicard.world 是**海外版**,仿爸的功能但外观大不同(XP 风格 + BIOS 开机动画 + 地区检测,代码名 luckycard_overseas)

## 第 0 章:空壳期(约 2026-02)— 点进去只有 404
- 域名挂上,没有任何页面,访问只有 404
- 爸爸的需求 → 开工
- **同期双打**:儿子加 **BIOS 开机动画**(第一个加的东西);爸爸**指挥 AI** 做了**浅色配色主页面**——大 **LUCKY** 图标居中 + 下面一排按钮(没人手写代码 😂)
- **小插曲**:儿子没跟爸说"动画播完要进主页"的思路 → 爸接的代码让动画**播完直接消失**,后面啥也没有(需求没对齐 😂)
- 之后儿子决定整体改成 XP 壳(爸爸:"挺酷的,继续做")

## 第 1 章:XP 壳成型
- **XP 壳是儿子让 AI(Hermes)写的**——早期会话记录随 key 删除丢失,AI 自己都不记得了,特此立传 📜
- XP 主题桌面:开始菜单 / 窗口 / 任务栏 (xp.js XPShell)
- bios.js:开机/引导 + 国内通知遮罩 + BSOD 模拟
- XP 风格**调了好几版**
- **小插曲**:爸给桌面背景直接塞了块**纯蓝色**,儿子内心 OS:"你不能上网搜个 Bliss 吗!"(后来才有蓝天草地那张)
- **为什么选 XP 而不是 95/98**:常听**音MAD**(语音输入打错成"音麦"),里面用的 Windows 提示音全是 XP 的系统音 → 听多了决定做 XP(爸爸评价"挺酷的",批准继续做)
